# Inheritance tax modelling

Code behind [Tax Policy Associates](https://taxpolicy.org.uk)' work on inheritance tax.

There are currently two projects here:

| Folder | What it is | Article |
|---|---|---|
| [`iht_modelling/`](iht_modelling/README.md) | Our model of every pensioner household in Great Britain: who would face inheritance tax if they died in April 2027, how many adults have money riding on it, and how that varies by constituency. Includes the interactive map. | [One in five pensioner households could face inheritance tax](https://taxpolicy.org.uk/2026/09/19/inheritance-tax-pensioner-households/) |
| [`tory_2026_proposal/`](tory_2026_proposal/README.md) | Our costing of the Conservative Party's October 2026 proposal to exempt the family home from inheritance tax: the static cost, the behavioural effects, who benefits, and what else the money could buy. Requires the iht_modelling project to be up and running.| Forthcoming |

Start with the README in each folder. Raw input data aren't included: almost all of it is free, but the main survey is licensed. The output folders contain aggregate results and charts. [`iht_modelling/DATA.md`](iht_modelling/DATA.md) has what you need and where to get it. Input files go in a `docs/` folder at the top of the repository.
